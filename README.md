# Sankalpa Catering

Sankalpa Catering is a simple static website for showcasing:

- South Indian chutney pudis
- Traditional laddus
- Vegetarian and Jain catering services

## Project Files

- `Sankalpa.html` - main website file
- `images/` - product and catering images
- `sankalpa-catalog.pdf` - exported PDF version

## Run Locally

Open `Sankalpa.html` in any browser.
